# motion-overlay

Example files for the `motion-overlay` tool in the CPM Lab ROS 2 workspace
(`ros2-workspace-lab`, under `tools/motion-overlay/`):

- `example_video.mp4`: example input video.
- `example_video_overlay.png`: the expected output for that video, generated with the default options.

Please do not delete or rename these files: the tool's README links to them.
